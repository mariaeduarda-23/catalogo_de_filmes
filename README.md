# **Projeto Catálogo de Filmes**
### Requisitos Funcionais

**RF01:**  O sistema deverá permitir que o usuário realize login por meio de usuário e senha.

**RF02:**  O sistema deverá permitir que o usuário cadastre um novo filme, informando título, ano de lançamento, gênero e nota.

**RF03:**  O sistema deverá permitir que o usuário faça o upload de uma imagem para ser utilizada como capa do filme.

**RF04:**  O sistema deverá permitir que o usuário visualize os filmes cadastrados em sua coleção, exibindo suas respectivas capas e informações.

**RF05:**  O sistema deverá permitir que o usuário edite as informações de um filme previamente cadastrado.

**RF06:**  O sistema deverá permitir que o usuário exclua um filme previamente cadastrado.

### Requisitos Não Funcionais

**RNF01:**  O sistema deverá garantir que somente usuários autenticados tenham acesso à coleção de filmes.

**RNF02:**  O sistema deverá possuir uma interface simples, intuitiva e de fácil utilização.

**RNF03:**  O sistema deverá apresentar as informações e imagens dos filmes em um tempo de resposta adequado.

**RNF04:**  O sistema deverá armazenar de forma segura e persistente os dados dos filmes e suas respectivas imagens.

**RNF05:**  O sistema deverá ser compatível com os principais navegadores utilizados para acesso ao sistema.
